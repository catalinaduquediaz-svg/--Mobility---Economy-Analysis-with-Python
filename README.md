# 🚗 Mobility Economy Analysis with Python

## 📌 Descripción

Proyecto de análisis exploratorio de datos desarrollado con Python para evaluar la relación entre la congestión vehicular y la productividad económica en distintas ciudades.

El análisis incluye limpieza de datos, exploración, visualización e interpretación de resultados con el objetivo de identificar patrones que apoyen la toma de decisiones.

---

## 🎯 Objetivo

Analizar si existe una relación entre los indicadores de movilidad urbana y variables económicas mediante técnicas de análisis de datos.

---

## 🛠️ Tecnologías utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
